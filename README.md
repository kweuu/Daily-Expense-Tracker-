# Daily Expense Tracker
Python Programming Project

Desktop app for tracking daily expenses, built with Tkinter and Matplotlib.

## Features
- Add expenses by category, amount (RM) and date (YYYY-MM-DD)
- Running total and delete of selected entries
- Filter the list by date
- Save the full list to CSV
- Analytics window with pie, bar and line charts by category

## Run
```bash
pip install -r requirements.txt
python3 main.py
```
